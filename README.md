# SARathi

> AI-assisted flood search-and-rescue coordination prototype developed for ORION-PS-04.

SARathi uses YOLOv8, Streamlit, SQLite and map-based incident tracking to demonstrate:

- Image and video object detection
- Human verification of AI detections
- Incident creation and mapping
- Manual SOS reporting
- Status tracking
- CSV export

## Important Disclaimer

SARathi is an academic prototype, not a certified emergency-response system. AI detections must be verified by a human operator before action.
